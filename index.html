🐱🛡️ PhishCat Security

Real-Time Web Component Integrity Verification

PhishCat Security is a browser extension prototype that monitors webpage components such as forms, iframes, and dynamic DOM changes to detect phishing behaviour in real time.

Demo Scenarios

✅ UiTM Student Portal

Legitimate login page with maintained component integrity.

🏦 Secure Bank Login

Simulates iframe injection as a suspicious external web component.
